## Code and test evidence

- Query validation, pending-exchange creation, model invocation, and persistence occur in the [chat service](../../../backend/domain/assistant/services/chat.py). The [assistant API errors](../../../backend/domain/assistant/api/errors.py) expose the existing conversation errors.
- The [chat routes](../../../backend/domain/assistant/api/routes.py) expose submission and conversation detail. The [shared limiter](../../../backend/bootstrap/extensions.py) defines the counting key and defaults. The [application factory](../../../backend/bootstrap/app.py) sets testing behavior.
- The [conversation aggregate](../../../backend/domain/assistant/models/aggregates.py) distinguishes answered history from the pending exchange. The [Gemini adapter](../../../backend/domain/assistant/infrastructure/adapters/gemini_chat_model.py) converts the supplied history into model turns.
- The [chat service tests](../../../backend/tests/domain/assistant/services/test_chat_service.py) capture calls, history, and answers. The [offline provider fixture](../../../backend/tests/domain/assistant/conftest.py) and [provider test](../../../backend/tests/domain/assistant/test_offline_provider.py) support inspection of the outgoing request without live credentials.
