# Design — Compare a manuscript with selected library sources

## Design

Each decision lists the requirements from [requirements.md](requirements.md) that it supports.

| ID | Decision | Components | Requirements |
| --- | --- | --- | --- |
| D-001 | Capture `editor.getText()` and the checked library entry IDs at send time. Capture an exact quote as its own field, not appended to the question text. Send the draft text only when Manuscript is checked. When Manuscript is unchecked, a quote still travels as its own field and no other draft text is sent. Send the snapshot in one exchange on the active conversation. | `ChatPanel.svelte`, `frontend/src/lib/api/chat.js`, `AskRequest` (`requests.py`), exchange route (`routes.py`) | R-001, R-002, R-003, R-005, R-006 |
| D-002 | Normalize the request into independent manuscript and library inputs. Decode the legacy `context_scope` values (`none`, `manuscript`, `source_library`) at the API boundary. In `ChatService._retrieve`, keep intersecting the requested IDs with the active sources of the authorized project (the `source_ids` callable wired in `container.py`) before any vector query. Use the live draft text directly instead of indexed manuscript chunks. | `requests.py`, `routes.py`, `ChatService` (`chat.py`), `container.py` | R-003, R-006 |
| D-003 | Embed the question, together with the quoted claim when present, and query eligible passages per source, so one source cannot use up the shared top-k. Attach the library entry ID and title to each supplied passage by adding the title to `RetrievedChunk` or to a new evidence value object. Add a semantic `EmbeddingGenerator` adapter (Gemini via `google-genai`) and wire it in `container.py`. The only generator today is the hash-based `InMemoryEmbeddingGenerator`. Use the same model for indexing and queries. Re-embed existing documents through the `IngestionWorker` reindex path when the model changes, in whichever `VectorStore` is wired (`InMemoryVectorStore` by default, `ChromaVectorStore` when configured). | `ChatService`, new Gemini embedding adapter, `IngestionWorker` and the source and manuscript handlers, `VectorStore` port and adapters, `value_objects.py`, `container.py` | R-004, R-005, R-006, R-008 |
| D-004 | Extend the `ChatModel` port so it receives the draft, the quote, the question and labelled source excerpts. Mark the quote as the comparison target, and pass it even when Manuscript is unchecked. Have the model cite excerpts by identifier, resolve identifiers to the supplied excerpts, discard identifiers that match no supplied excerpt so only supplied library evidence is cited, and return the citations with the answer so the UI can render source titles. The exchange route therefore returns more than `{answer}`. | `ChatModel` port, `GeminiChatModel`, `ChatService`, `routes.py`, `value_objects.py`, `ChatPanel.svelte`, test `FakeChatModel` | R-004, R-005, R-007, R-011 |
| D-005 | One Context dropdown replaces the three scope buttons and the separate source picker. It has a scrollable, title-filtered source list and fixed Web, Manuscript and Clear selection controls. A new chat starts with Web alone, and the closed button summarizes the selection (for example "Web" or "Manuscript + 2 sources"). Checking or unchecking takes effect immediately with no Apply step. Arrow keys move focus, Space toggles the focused item, and Escape closes the dropdown and returns focus to the Context button. Checking or unchecking Manuscript or a source leaves Web as it was. Unchecking the last checked item, or choosing Clear selection, leaves only Web checked. Filtering never clears checked items. Quoting never changes the checked items. Remove the per-selection `sessions` key. Keep conversation identity independent of filtering, quoting and selection changes. "All indexed sources" is the only bulk-selection checkbox. Derive its indicator from the indexed IDs of the whole project list, including entries hidden by the filter. Checking every source checks it, and unchecking one source clears it. It is disabled when no sources are indexed. Bulk selection copies that set once and preserves Web and Manuscript. Sources indexed afterward stay unchecked until the writer checks them. The assistant context exposes a read endpoint that returns the project's searchable library source IDs from `IndexedDocumentRepository`. It excludes manuscript documents, which `OnManuscriptSaved` also indexes in the same repository, by intersecting with the project's active source IDs (the `source_ids` callable in `container.py`). The frontend joins those IDs with the titles from `listSources`, so `assistant` and `src_lib` never import each other's services. | `ChatPanel.svelte` or a new Context dropdown component, `chat.js`, `sources.js`, assistant `routes.py`, `IndexedDocumentRepository` | R-001, R-002, R-009, R-010 |
| D-006 | Encode Web and Manuscript independently of the selected source UUIDs. Web alone keeps the existing scope `none`, sent with empty manuscript text and null source IDs. Accept selections above 1,000 IDs without truncation and batch downstream work. On a successful exchange only, store the Web and Manuscript flags and the selected ID and title pairs on the `Conversation`. Add defaults for old Mongo documents. Return them from `_conversation_json`. On restore, show a record saved with scope `none` as Web alone. Decode a legacy `manuscript` record as Manuscript with Web off, and a legacy `source_library` record as its sources with Web off. The intake does not specify this mapping, so T-002 confirms it. Convert a legacy all-library selection (`source_ids` null) into an explicit set from the project. Name a removed source from its stored title and keep the remaining choices checked. | `Conversation` (`aggregates.py`), `InMemoryConversationRepository`, `MongoConversationRepository`, `_conversation_json` in `routes.py`, `requests.py`, `ChatPanel.svelte` | R-001, R-002, R-011, R-012 |
| D-007 | Attempt to search every selected source and isolate a failed search to its source. Apply the calibrated cosine threshold inclusively (at or above) to `RetrievedChunk.score`. Keep the threshold and the passage budget in configuration, set by calibration and testing. Allocate eligible passages in rounds across sources, trying smaller fitting passages before marking a source omitted for capacity. Compute the evidence budget from the configured model window minus tokens for instructions, history, question, selected draft, quote, formatting and reserved response. Count the assembled request through a new token counter port before dispatch. Replace the blanket `except Exception` in `_retrieve` with per-source outcomes: unavailable, searched without a match, matched but omitted for capacity. | `ChatService` and `_retrieve`, `VectorStore` adapters, a new token counter port with a Gemini-backed adapter, `container.py` | R-007, R-008, R-011 |
| D-008 | Pass named per-source outcomes and only the admitted excerpts to the model. Distinguish support, qualification and conflicting facts. Mark a claim that cannot be checked as unverifiable and never as contradicted. Continue with usable evidence, and when no selected source supplies any, say the claim could not be verified from the selection. Web enables separately identified model knowledge and adds no browsing. With Web off, instruct the model to base factual findings only on the manuscript and the selected sources. | `ChatModel` port, `GeminiChatModel` system instruction and prompt builder, `ChatService` | R-004, R-007 |
