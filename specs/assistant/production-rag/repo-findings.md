Reviewed the working tree at HEAD `260474b` against the [ticket](../../../tickets/assistant-rag.md), [intake](brief.md), and [Gherkin scenarios](gherkin.feature). Findings come from source and test inspection. Runtime behavior remains unverified.

| S-019, S-024 | The default chunker emits one chunk per nonblank paragraph, in order, with a position and SHA-256 content hash. Whitespace yields no chunks. A single long paragraph can exceed the token budget, and adjacent paragraphs share no deliberate overlap. | Exercise one paragraph longer than the token budget. Check each chunk's token count, positions, hashes, and overlap against the input. Check blank input directly at the chunker boundary. |
| S-020, S-027 | Ingestion and chat receive the same embedding generator. Its default implementation hashes text into 32 values per chunk. It preserves order and dimension but does not encode semantic similarity. | Exercise both indexing and querying with the model already available locally. Check vector count, dimension, order, and the paraphrase ranking from S-027. Detect outbound requests on both paths, including requests to services other than AI providers. |
| S-021, S-025 | Normal startup uses the container defaults for all three adapters. Mongo startup supplies repositories and delegates to the same builder. A Chroma adapter already supports a persistent path, but production startup does not supply it. | Index a passage through production wiring using an isolated storage location, reopen it through fresh wiring, and retrieve the passage. Separately check default test startup for in-memory adapters and zero writes to production storage. |
| S-022, S-026 | The subscribed removal handler returns for an unknown source and marks an indexed record stale. It receives only the repository, although both vector stores support deletion by document reference. It skips records currently being indexed. | Remove one of two indexed sources through the event path. Inspect stored vectors directly so marking the record stale cannot mask a missed deletion. Verify the second source stays searchable and removal of an unknown source succeeds. |
| S-023 | The assistant tests include an opt-in fixture that blocks socket connections and DNS lookups and supplies a fake Gemini client. It exercises the provider boundary. | Verify the RAG scenarios offline without live credentials, including retrieval with a locally available semantic model and persistence across startup. A fake provider response alone cannot establish those outcomes. |

## Code and test evidence

- The ingestion worker calls the chunker, embeds the resulting chunks, and upserts them. It treats an empty chunk list as an ingestion error. S-024 concerns the chunker result, so it does not imply that indexing blank text succeeds. [Chunker](../../../backend/domain/assistant/infrastructure/adapters/in_memory_document_chunker.py) · [Ingestion worker](../../../backend/domain/assistant/services/ingestion_worker.py)
- Chat embeds the writer's query through the generator supplied by the assistant module before querying the vector store. [Default embedding generator](../../../backend/domain/assistant/infrastructure/adapters/in_memory_embedding_generator.py) · [Chat service](../../../backend/domain/assistant/services/chat.py) · [Assistant module](../../../backend/bootstrap/contexts/assistant/module.py)
