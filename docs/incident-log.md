# Delivery incident log

Include every build failure that reached `main` and every failed production deployment. Reconcile GitHub Actions runs on `main`, Render deployment history, and incident issues before each consultation.

| Date and time | Impact and evidence | Root cause | Fix or rollback | Recovery verified | Prevention and owner |
| --- | --- | --- | --- | --- | --- |
| Pending evidence review | Reconcile Actions, production deploys, and GitHub issues | Pending | Pending | Pending | Pending |

For a production incident, use the [incident issue template](../.github/ISSUE_TEMPLATE/production-incident.md). Link the failing job or deploy, the corrective PR or deployment, and the first verification that established recovery. Record unknown causes as under investigation and assign a follow-up.
